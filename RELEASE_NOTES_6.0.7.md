# MKV Encoder Q 6.0.7

When an MP4 or other non-MKV is sent from Encoder to Cleaner, the **Waiting for Encode** row shows the source filename and extension. On a successful encode, Cleaner replaces that row with the actual MKV and queues it for cleaning. If the encode is skipped, fails, or is cancelled, the row shows **Not Cleaned** with the reason.
