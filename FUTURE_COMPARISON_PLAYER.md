# Comparison player status

The core comparison idea is now prototyped in 6.0 Beta 1: local VLC playback,
shared controls, a side-by-side view, and detachable video windows for manual
placement across monitors. Files are read directly without association changes.

Future work depends on testing: seek alignment across different codecs,
4K hardware decode, HDR appearance across different monitors, matching zoom,
fullscreen controls and optional self-contained VLC runtime packaging.
